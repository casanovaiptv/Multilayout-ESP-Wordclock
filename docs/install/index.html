ESP Wordclock – ESP32

USB-Webinstaller für klassische ESP32-Boards (`esp32dev`). Nicht für ESP32-C3 oder ESP8266.

Firmware-Paket wird geprüft …

Nur in einem kompatiblen Chromium-Browser über HTTPS oder localhost. Vor dem ersten Einsatz die Firmware auf Testhardware prüfen und Einstellungen sichern. Kein automatisches vollständiges Löschen vorgesehen.
